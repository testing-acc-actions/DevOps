# DevOps Engineering Academy

A dark, browser-based personal DevOps learning dashboard. Open **[index.html](./index.html)** to start.

## Enable the hosted website with GitHub Pages

1. Open this repository's **Settings**.
2. Select **Pages** in the left sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Set branch to **main** and folder to **/(root)**, then select **Save**.
5. Wait for GitHub Pages to finish publishing. Your site will be:

   https://testing-acc-actions.github.io/DevOps/

## What is included

- Beginner-to-production roadmap across 14 stages.
- Concept explanations, examples, use cases, question prompts and answer guidance.
- Production incident scenarios and structured investigation approaches.
- Labs and progressive projects.
- Integrated Employee Management application capstone.
- Senior-engineer tips, attendance, study timer and evidence-based self-assessment.
- Local progress storage and JSON export.

## Progress and privacy

- Progress is stored in the browser's local storage on the device/browser you use.
- It is not automatically synchronized with GitHub or other devices.
- Use **Attendance & tracker → Export my progress (JSON)** for backups.
- The timer measures page-open time; it cannot verify attention.
- Ratings are self-assessments. Independent skill evaluation requires reviewing actual answers, lab evidence and troubleshooting decisions.

## Cost and security

The site is static and does not require AWS or other cloud resources to run. For cloud labs, check current pricing, configure a budget, use least privilege, avoid committing credentials/secrets, and destroy temporary resources after validation.
